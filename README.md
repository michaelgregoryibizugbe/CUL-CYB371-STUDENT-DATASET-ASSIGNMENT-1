# CUL-CYB 371 - Data Mining and Data Warehousing: Assignment Two

A fictional student dataset generated with Python.

## Fields
1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

## How to run
```bash
python3 generate_dataset.py
```

This creates `students.csv` with 50 fictional student records (seeded, so results are reproducible).

## Files
- `generate_dataset.py` - Python script that creates the dataset
- `students.csv` - the generated dataset
